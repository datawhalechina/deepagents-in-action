LangGraph 中断的运行时机制 — 暂停、保存、恢复与节点重放

目标：为中文技术课程生成一张清晰、可读、与本课程既有插图风格一致的 16:9 流程图，用于解释 LangGraph `interrupt()` 的底层执行过程。画面应帮助读者理解：中断不是普通输入框，而是一次可持久化、可恢复的图执行暂停。

风格参考：会随生成命令传入现有课程流程图作为 reference。必须学习它们的字体、线条、版式与留白：
- 白板 / Notion 手绘课程图，不要像现代 SaaS Dashboard 或 Keynote 模板
- 中文字体是圆润、轻松的手写 marker 风格，笔画自然，不是黑体、思源黑体、苹方、粗体标题字
- API 关键词是小号手写 monospace / marker 风格，作为辅助标签，不要喧宾夺主
- 线条是轻微手绘感的深灰细线，箭头可有铅笔阴影或斜线填充
- 背景是轻微纸张纹理或很浅的灰白，不要纯白发光，不要玻璃拟态
- 卡片边框是薄的、略圆角、略手绘，不要厚重阴影和立体按钮

画面标题：
「LangGraph 中断机制：保存状态，再恢复执行」

整体布局：
- 16:9 横向课程图，浅色背景，适合网页文章阅读
- 主流程从左到右，分为 6 个主要节点
- 第 3 个节点「保存检查点」和第 6 个节点「节点从头重放」需要明显强调
- 所有主文字必须是简体中文，API 关键词可以作为小号英文标签保留
- 不要使用复杂 3D、照片、拟物插画、过多装饰图标
- 不要出现额外英文段落，不要把图画成代码截图

主流程节点：
1. 「节点执行」
   - 小标签：业务逻辑运行中
   - 图标：小齿轮或流程节点

2. 「调用中断」
   - 小标签：interrupt(value)
   - 图标：暂停符号
   - 使用淡黄色高亮，表达“暂停”

3. 「生成中断对象」
   - 小标签：包含 value 与 id
   - 图标：带 ID 的小卡片
   - 强调 `id` 是后续恢复匹配的关键

4. 「保存检查点」
   - 小标签：状态、下一步、待恢复中断
   - 图标：数据库圆柱 + 书签
   - 使用淡蓝色高亮，表达“持久化”

5. 「人类返回结果」
   - 小标签：Command(resume=...)
   - 图标：用户头像 + 回传箭头
   - 下方用小卡片显示两种恢复值：
     - 「单个中断：直接值」
     - 「并行中断：按 id 映射」

6. 「恢复执行」
   - 小标签：同一 thread_id
   - 图标：播放按钮或继续箭头

在第 6 个节点右侧或下方增加醒目的提醒框：
「恢复时不是从中断行继续，而是从节点开头重放」

提醒框下方画一个小回环箭头：
- 从「恢复执行」回到「节点执行」
- 箭头标签：节点重放
- 在回环旁边标注：`interrupt()` 读取恢复值后直接返回

底部小提示条，三点即可，不要太密：
- 「不要用宽泛的 try/except 包住 interrupt()」
- 「中断前副作用要幂等」
- 「并行中断用 Interrupt.id 绑定答案」
